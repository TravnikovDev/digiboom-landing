# Launch copy pack

Ready-to-post copy for the community push (**B7** in [TODO.md](TODO.md)). Post these from
your own accounts — a founder replying in the comments converts, a brand account does not.

## Ground rules that decide whether this works

1. **Do not drop a link and leave.** Every one of these communities punishes that. Answer
   every comment for the first 24 hours; that is where the signups come from.
2. **Read each subreddit's self-promotion rule first.** Some require a flair, some
   restrict promo to a weekly thread, some ban links from new accounts. Breaking the rule
   gets you removed and remembered.
3. **Lead with the problem you personally have.** You run Neurofashion. You are not a
   marketer with a product; you are a seller who got annoyed. That is the whole
   credibility of this launch.
4. **Space them out.** One community per day, not five in an hour.
5. **Never fake numbers.** No "hundreds of sellers waiting" while it is 0. The honest
   version is more persuasive anyway, and this niche can smell it.
